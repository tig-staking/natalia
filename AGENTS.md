# Agent guidance

Before implementing or modifying significant UI, read `docs/DESIGN_SYSTEM.md`.

For any work involving the Natalia character, also read `docs/CHARACTER_BRIEF.md`.

Reuse existing design tokens and components. Do not introduce unrelated colors, typography, icon styles, illustration styles, spacing systems, or animation conventions unless the design system is intentionally updated.

Keep real reference photographs private and outside Git. Never commit files from the ignored `foty/` directory.
